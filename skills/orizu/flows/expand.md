# Expand

post-win, appetite-driven: pick the next instruction surface from Onboard's inventory by the same quick-win criterion and run the loop there.

Reach for Expand after Promote when the user wants to bring another instruction surface into Orizu.

## Revisit the inventory

Start from Onboard's inventory and prior rationale. If code, ownership, models, traffic, labels, evals, or failure evidence changed, follow `references/assess-and-plan.md` to refresh the inventory before ranking another surface.

## Select the next quick win

the recommended starting point for a repo new to Orizu: the instruction surface with the shortest credible path to a **measured, promotable model improvement**.

Apply that same criterion across the remaining surfaces using source metadata only: availability, provenance, coverage, approved-ground-truth metadata or a credible labeling path, measurable failure-mode metadata, execution access, and a realistic promotion path. Do not open or sample customer records while selecting. Present the recommendation and tradeoffs; proceed after the human agrees on the next surface.

## Persist the selected-surface plan

For every selected next surface, unconditionally follow `references/assess-and-plan.md` to resolve its decision ledger, obtain explicit human ratification, write and commit its complete plan at the canonical path, and complete the required workbench memory update when applicable. The previous surface's committed plan cannot authorize data access or execution for this one. Do not begin First win until this persistence workflow is complete, even when the inventory itself did not need refreshing.

## Run the loop there

Run `flows/first-win.md` for the selected surface, then `flows/promote.md` for its report, validation, and human promotion decision. Keep datasets, judges, model-config profiles, evidence, and production pointers scoped to the new surface; apparent similarity is not proof that another surface's artifacts remain valid.

## Exit criterion

The selected instruction surface has completed First win and Promote with its own evidence and a recorded human promotion decision. The refreshed inventory remains available for a later Expand choice without implying a forced sequence.
